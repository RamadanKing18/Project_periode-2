Welke vaardigheden heb ik in bezit?

Ik ben momenteel bezig met het ontwikkelen van mijn programmeervaardigheden. Ik heb basiskennis van HTML en CSS en ben daarnaast aan het leren programmeren met Lua in Roblox Studio. Voor mijn projecten maak ik gebruik van Visual Studio Code en Roblox Studio. Op dit moment werk ik aan mijn eigen portfolio, waarin ik mijn kennis van HTML en CSS in de praktijk breng. Daarnaast ben ik bezig met verschillende projecten in Roblox Studio, waarbij ik leer hoe ik games kan ontwikkelen en scripts kan schrijven. Naast mijn technische vaardigheden beschik ik ook over persoonlijke vaardigheden. Ik ben creatief, kan problemen oplossen, heb doorzettingsvermogen en kan goed samenwerken. Ik vind het belangrijk om mezelf te blijven ontwikkelen en nieuwe kennis op te doen, zodat ik in de toekomst een goede softwareontwikkelaar en engineer kan worden.
